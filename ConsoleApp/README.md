# АИС

## Главное меню
В меню 7 опций:
* __list of mods__ - вывести на экран весь список модов, 
* __create__ - создать новый мод, 
* __read__ - просмотреть более подробно _один конкретный мод_, 
* __delete__ - удалить _один конкретный мод_, 
* __update__ - изменить данные в _одном конкретном моде_, 
* __add to modpack__ - добавить _один конкретный мод_ в сборку модов, 
* __delete from modpack__ - удалить _один конкретный мод_ из сборки модов, 
* __all mods from modpack__ - вывести на экран весь список модов, которые есть в конкретной сборке модов, 

## Особенности
* _Конкретный мод_ - это мод, который ищется по ID.
Если ввести ID несуществующего мода, то выведется предупреждение и программа попросит ввести айди заново.
Если ввести _пустую строку_, то программа прервёт операцию и вернёт обратно в главное меню.
* _При создании мода_ ID должно быть уникальным, иначе программа даст предупреждение и попросит его ввести заново.
* _При изменении мода_ можно пропустить ввод данных в каком-то поле отправив пустую строку, тогда мод получит старые данные из этого поля.
* _При удалении из сборки модов_ если ввести несуществующую сборку, то программа даст предупреждение и отправит в главное меню.

## Ввод данных
Программа читает только латинский алфавит.

Если программа попросит ввести логические данные (bool), то нужно ввести одно из этих значений:
`1, y, yes, true` (да) или `0, n, no, false` (нет).

Если программа попросит ввести текст (text), то она будет читать все следующие строки, пока вы не отправите пустую строку.

Если программа попросит ввести версию (version), то нужно ввести значение строго по шаблону:
* `v[число].[число].[число] (ALPHA)`,  Пример: __v1.0.0 (ALPHA)__
* `v[число].[число].[число] (BETA)`,  Пример: __v1.0.0 (BETA)__
* `v[число].[число].[число] (RELEASE)`,  Пример: __v1.0.0 (RELEASE)__

Также версию можно ввести более коротким способом:
* `[число].[число].[число]a`,  Пример: __1.0.0a__ -> __v1.0.0 (ALPHA)__
* `[число].[число].[число]b`,  Пример: __1.0.0b__ -> __v1.0.0 (BETA)__
* `[число].[число].[число]r`,  Пример: __1.0.0r__ -> __v1.0.0 (RELEASE)__
