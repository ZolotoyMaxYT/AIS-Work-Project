# АИС

## Главное меню
Сверху расположен список всех модов, каждый мод можно либо удалить, либо просмотреть более детально.

Ниже списка расположена кнопка для создания нового мода.

## Создание мода
Нужно ввести подходящие значения в подходящие поля:
Айди мода, имя мода, автор мода, описание мода, версия мода, тип мода, оценка мода и список сборок в которые он входит.

Особенности:
* __Айди мода__ должно быть уникальным;
* __Сборки модов__ в списке нужно разделять новой строкой.
* __Оценка__ - это число с знаком (положительное, отрицательное или ноль)

## Просмотр мода
Окно, в котором можно просмотреть всю информацию о моде более подробно.

Сверху-слева находится `[айди мода] имя мода`, сверху-справо: автор, версия, оценка, и тип мода.

Чуть ниже расположено описание мода.

Ещё ниже - список сборок, в которые входит мод.

В самом низу находится кнопка для открытия окна редактирования мода.

## Редактирование мода
Нужно изменить подходящие значения в подходящих полях:
имя мода, автор мода, описание мода, версия мода, оценка мода и список сборок в которые он входит.

Особенности:
* __Айди мода__ нельзя изменить;
* __Тип мода__ нельзя изменить;
* __Сборки модов__ в списке нужно разделять новой строкой.
* __Оценка__ - это число с знаком (положительное, отрицательное или ноль)
